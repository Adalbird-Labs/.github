# Security policy

Security and privacy issues should be reported privately.

## Reporting a vulnerability

Please email **contact@adalbirdlabs.com** with:

- the affected product or repository,
- a clear description of the issue,
- reproduction steps or proof of concept where appropriate,
- potential impact,
- any suggested mitigation.

Do **not** open a public GitHub issue for an undisclosed vulnerability and do not include credentials, private tokens, personal data or other sensitive information in public discussions.

We will review the report and coordinate next steps through a private channel.

Project-specific security instructions override this default when present.
